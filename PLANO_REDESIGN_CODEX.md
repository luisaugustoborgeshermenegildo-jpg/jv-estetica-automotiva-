# JV Estética — proposta Codex

Tipo: serviço local. Objetivo: apresentar os cuidados para motos e carros e conduzir a uma solicitação de agendamento de moto ou conversa sobre carro.

Referência aprovada pelo pedido: preto e azul, tipografia grande, composição com grade e alternância de áreas claras e escuras. A direção do Luis prevalece sobre os sorteios de cores e layouts das skills.

1. Preservar conteúdo, preços, contatos e contrato da API existente.
2. Criar interface responsiva com hero fotográfico, serviços comparáveis e agendamento acessível.
3. Manter a reserva de moto na API; carros são consulta pelo WhatsApp, pois a API base não aceita esse tipo de veículo.
4. Conferir build, estados do formulário, teclado, movimento reduzido e larguras de celular/tablet/desktop.
5. Revisar o diff e apresentar a versão para comparação antes de qualquer commit ou publicação.

Skills: Taste Skill e Frontend Design para composição, hierarquia e acabamento. Sem trocar a tecnologia HTML/CSS/JavaScript existente. Dados reais do repositório prevalecem sobre contatos fictícios das demonstrações das skills.
